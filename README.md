A one-star review from a house cat about its human, written as a tiny
Node 22 program. Running `main.ts` writes the single-line review to
`/output/entry.txt` (under 200 characters, deadpan review shape, with a
sting in the last words).

Entry for [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) on [make.fun](https://make.fun/r/tmbrnhrj).

## Run

```sh
node main.ts
cat /output/entry.txt
```
